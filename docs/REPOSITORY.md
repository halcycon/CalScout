# Repository maintenance

CalScout uses Tailor v0.5.0 for community health files, issue/PR templates and
managed Just/Nix loaders. `.tailor.yml` declares MPL-2.0 and repository settings.
This checkout has no GitHub remote: no hosted repository was created, settings
applied, labels published or code pushed by the setup. Once a remote exists,
`tailor docket` identifies the target and `tailor baste` previews remote changes.

For template updates, install [Tailor](https://github.com/wimpysworld/tailor), run
`tailor measure` and `tailor baste`, review the diff, then run `tailor alter`.
First-fit community files preserve CalScout's project-specific instructions.
Dependabot is project-owned (unmarked), with npm and GitHub Actions updates.
Tailor's default Go/Nix update rules do not match this extension. Funding, Pages,
MCP servers, Go/Rust/Python application scaffolds, Nix flake and direnv are disabled;
the small shared Nix loaders are generated by Tailor but no Nix shell is required.
The missing FUNDING.yml in `tailor measure` is intentional.

Runtime source remains in `src/`, tests in `tests/`, build helpers in `scripts/`,
and usage/security/release documentation in `docs/`. The architecture, compatibility,
testing and implementation-plan documents remain at the root as required by the
project brief. Root SECURITY.md is the reporting policy; docs/SECURITY.md explains
the extension's security model. The original brief and MPL license are retained.

## Quality commands

```sh
npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
npm run check
npm test
npm run build
```

`npm run check` checks source/JSON syntax, ESLint and Prettier formatting. Use
`npm run format` to format JavaScript, HTML, CSS and unit tests. Ruff checks and
formats Python helpers; run it from the venv or activate that venv first.
`npm audit` checks development dependencies too. A minimatch override selects the
patched 11.0.5 release while ESLint 10's dependency range still selects an affected
10.x version; remove it when the upstream range is patched and audit remains clean.

With Just, actionlint and the venv tools on PATH:

- `just build` builds the XPI.
- `just test` runs unit/protocol tests.
- `just lint` checks workflows, JavaScript and Python.
- `just lint correct` applies safe ESLint/Ruff fixes and formats code, then checks.

Keep extension commands in `just/project/*.sh`; Tailor owns `just/tailor.just`,
`just/loader.just` and shared Nix fragments. The root justfile imports the managed
loader. CI runs the same source checks and verifies package reproducibility.
Native acceptance tests remain explicit commands in TESTING.md.
