# Security Policy

## Supported Versions

CalScout is a development MVP targeting Thunderbird 156. Report vulnerabilities against the current source or latest development XPI. See [the security model](docs/SECURITY.md) for the privileged API boundary and known testing limits.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

[Report vulnerabilities privately](../../security/advisories/new). Include:

- Steps to reproduce
- Affected versions
- Potential impact

This project is maintained on a best-efforts basis. There are no guaranteed response times for security reports.
